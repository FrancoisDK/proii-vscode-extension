# 🎉 Version 1.0.1 - .std File Support Added!

## What's New

Your PRO/II VS Code extension now supports **both `.inp` AND `.std` files**!

### ✅ Changes

- **File Extensions**: Now recognizes `.inp` and `.std` files
- **Full Support**: Both file types get complete syntax highlighting
- **Full Support**: Both file types get all 43 code snippets
- **Automatic**: Just open any `.std` file and it works!

- **File**: `proii-language-support-1.0.1.vsix`
- **Size**: 45.41KB (23 files)

## What This Means

Your currently open file **`SBO.std`** will now have:
- ✅ Full syntax highlighting (all 200+ keywords)
- ✅ All 43 code snippets available
- ✅ Inline comments with `$`
- ✅ Bright yellow `&` continuation
- ✅ Bright yellow arithmetic operators
- ✅ All the same features as `.inp` files

## How to Update

### If you already have v1.0.0 installed:
1. Uninstall the old version (Extensions → PRO/II Language Support → Uninstall)
2. Install the new version:
   - Extensions → `...` → Install from VSIX
   - Select: `proii-language-support-1.0.1.vsix`
3. Reload VS Code
4. Open your `SBO.std` file - it should now have syntax highlighting!

### If this is your first install:
1. Extensions → `...` → Install from VSIX
2. Select: `proii-language-support-1.0.1.vsix`
3. Open any `.inp` or `.std` file

## Verification

After installing, check:
- Open `SBO.std` 
- Status bar should show "PRO/II"
- Keywords should be color-coded
- Type `flash-adia` and press Tab - snippet should expand
