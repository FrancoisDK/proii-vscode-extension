## 📦 What's New in v1.3.0

### Comprehensive Documentation Added (~1,420 lines)

Four commonly used unit operations received major documentation expansions:

#### 1. **SPLITTER** (~420 lines) ✅
**Most Valued Unit** - Complete specification guide

- **5 Specification Types:**
  - Total Rate Specification
  - Fractional Specification
  - Component Rate Specification
  - Recovery Specification
  - Referenced Specification

- **Key Features:**
  - Detailed FILL vs NORMALIZE comparison with examples
  - ENRICH and IMPURE product handling
  - Multiple comprehensive examples (5+ scenarios)
  - Design guidelines for stream splitting
  - Troubleshooting common issues
  - Cross-referencing capabilities

#### 2. **PIPE** (~300 lines) ✅
Complete pressure drop and piping hydraulics

- **7 Pressure Drop Correlations:**
  - BBM (Beggs-Brill-Moody) - General purpose
  - Olimens - Vertical pipes
  - DEF (Dukler-Eaton-Flanigan) - Horizontal pipes
  - Mukherjee-Brill - Inclined pipes
  - Gray - Gas wells
  - Hagedorn-Brown - Oil wells
  - Palmer - High-pressure gas

- **11 Device Types:**
  - DPIPE, DREG, DORIFICE, DCHECK, DBEND, DTEE, DNOZZLE
  - DENTRANCE, DEXIT, DCONTRACTION, DEXPANSION, DKFACTOR, DVALVE

- **Key Features:**
  - Elevation handling (positive/negative)
  - Segmentation (1-200 segments)
  - Friction factors (Moody, Colebrook-White, Jain)
  - Heat transfer (DUTY, ISOTHERMAL, U+TAMBIENT)
  - Line sizing mode (DPMAX, VMAX, PMIN)
  - Configuration parameters (LENGTH, DIAMETER/NPS, AROUGH/RROUGH)

#### 3. **FLASH** (~350 lines) ✅
Complete flash drum and phase separation

- **10 Flash Types:**
  - ISOTHERMAL - Fixed T and P
  - ADIABATIC - Most common, no heat transfer
  - DEW - Saturated vapor
  - DEWHC - Hydrocarbon dew point
  - DEWWATER - Water dew point
  - BUBBLE - Saturated liquid
  - ISENTROPIC - Constant entropy
  - UPPERDEWPOINT - Upper dew point solution
  - TPSPEC - Fixed T or P with SPEC
  - FRAC - Specified vapor fraction

- **Key Features:**
  - VLLE three-phase support (V, L, W products)
  - Entrainment specifications (FROM/TO phase)
  - Product phase assignment (super-critical handling)
  - Column attachment options
  - Detailed convergence parameters
  - 5+ comprehensive examples

#### 4. **HX (Simple Heat Exchanger)** (~350 lines) ✅
Complete heat exchanger configurations

- **7 Exchanger Configurations:**
  - One-Sided - Infinite heat source/sink
  - Two-Sided - Process-to-process exchange
  - Utility - Water/air/steam cooling/heating
  - Attached Condenser
  - Attached Reboiler
  - Attached Pumparound
  - Attached Side heater/cooler

- **17 Performance Specifications:**
  - DUTY, HTEMP, CTEMP (basic)
  - HOCI, HICO, HOCO, TMIN, MITA (approach temps)
  - HLFRAC, CLFRAC (phase fractions)
  - HDTBB, CDTBB, HDTAD, CDTAD (subcool/superheat)
  - COCI, HIHO (temperature changes)
  - UA (overall heat transfer)

- **5 Utility Options:**
  - WATER - Sensible heat cooling
  - AIR - Air cooling
  - STEAM - Latent heat heating
  - HEATINGMEDIUM - Thermal oil heating
  - REFRIGERANT - Refrigeration cooling

- **Key Features:**
  - Zone analysis (OUTPUT, CALC, PLOT modes)
  - Shell and tube configurations (N:2N passes)
  - Counter-current vs co-current flow
  - Column attachment capabilities
  - Temperature crossover detection
  - Design guidelines and troubleshooting

## 📥 Installation

### Method 1: VS Code Extensions View
1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Click "..." menu → "Install from VSIX..."
4. Select `proii-language-support-1.3.0.vsix`
5. Reload VS Code

### Method 2: Command Line
```powershell
code --install-extension proii-language-support-1.3.0.vsix
```

## 🎯 Usage

### Hover Tooltips:
1. Open any `.inp` file
2. Hover over unit operation keywords:
   - `SPLITTER` - See all 5 specification types
   - `PIPE` - See pressure drop correlations
   - `FLASH` - See all 10 flash types
   - `HX` - See exchanger configurations
3. View comprehensive examples, design guidelines, and troubleshooting

### Syntax Highlighting:
- Automatic syntax highlighting for `.inp`, `.std`, `.out` files
- Color-coded keywords, parameters, and comments
